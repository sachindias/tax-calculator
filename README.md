# A Simple Tax Calculator

This is a simple tax calculator with the aim of giving lots of flexibility and a detailed breakdown of where money is coming from and going to.

You can use this to:
- estimate how much tax, NI and student loans you are paying.
- How your bonus will affect that month's pay.
- How pensions & salary sacrifice affect the amount of tax you pay (and in which band).

# How to use it

Simply clone the repo and run the following commands.

```
npm install
npm run dev
```
